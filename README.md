# Quad Reflex

파란색은 누르고 빨간색은 참는 4칸 반응속도 테스트 웹앱입니다.

## 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

## 배포

Vercel 또는 Netlify에서 이 폴더를 GitHub 저장소로 연결해 배포하세요.
Vite 기본 빌드 명령은 `npm run build`, 출력 폴더는 `dist`입니다.
